二、 结构化评估报告

1\. 底层数据层适配性评估（暴露最大短板）

适配表现： 极度不平衡。行情和财务数据（AKShare）适配良好，但新闻/舆情数据严重水土不服。

具体表现与根因：

新闻数据完全错位： 在分析长江电力（600900.SH）和神火股份（000933.SZ）时，原生新闻获取模块由于找不到A股资讯，直接拉取了“英伟达与Marvell合作”、“K型经济”、“标普500 VOO”等纯海外宏观与美股科技股新闻

。这导致后续的情绪分析师在A股标的上给出了毫无关联的结论（如建议传统铝业股警惕AI泡沫

）。

缺失A股特色定价数据： 框架缺少北向资金、融资融券、龙虎榜席位流向数据，而这些往往是A股短线定价的核心驱动力。

对结果的影响： 导致短线交易分支在缺乏国内“政策市”信息输入的情况下，几乎变成了纯技术面和滞后财务数据的盲测。

2\. 多智能体角色的A股本土化适配性评估

基本面分析师：部分适配。 原生逻辑看重PE/PB和流动比率。例如在分析长江电力时，系统因其流动比率仅为0.22而拉响警报

。幸好DeepSeek在辩论环节展现了强推理，指出“重资产公用事业低流动比率是常态”

，挽回了原生逻辑的死板。但基本面分析依然忽略了A股特有的“中特估（国企估值重塑）”和“高股息政策导向”因子。

技术分析师：严重水土不服。 框架完全照搬美股ATR止损和均线交叉逻辑。例如建议神火股份“在28.50元设置紧密止损”

。在A股T+1和10%跌停板规则下，如果当天遭遇跌停或次日一字跌停，这种“紧密止损”根本无法执行，会导致极大的实盘滑点。

多空辩论与风险控制：基本适配。 辩论机制是最大亮点。对于601298.SH（无交易数据标的），风险委员会和交易员完美识别了“退市/长期停牌”的毁灭性风险，拒绝了激进派“盲盒抄底”的建议，给出了“坚决规避/卖出”的明智决策

。

长/短线决策差异： 新增的定投分支（DCA）高度适配A股。 在长江电力的压测中，模型准确抓取了2022年熊市和2023-2024利率敏感期的表现

，这种基于A股“牛短熊长”特性设计的微笑曲线回测，实操价值远高于原生短线分支。

3\. 分析结果与交易建议的A股可执行性评估

报告本土化不足： 原生框架强制输出英文或半中半英报告（如 Technical Analysis Report for 600900.SH

）。这不仅不符合A股研究员的阅读习惯，还容易引发大模型在专业术语翻译上的歧义。

交易择时失效： 交易员给出的操作计划（如“突破32.50元追多”

）缺乏对A股集合竞价阶段（9:15-9:25）和盘中异动的考量，直接将其转化为实盘API极易因流动性缺失或涨跌停导致废单。

三、 缺陷清单与优化优先级（P0/P1/P2）

P0（紧急必须修复）：新闻舆情数据源错位与LLM幻觉

缺陷表现： 抓取美股科技新闻用于A股传统企业分析

。

优化方案： 彻底重构 news\_analyzer 模块的数据获取函数。

代码级修改： 接入 AKShare 的 ak.stock\_info\_a\_code\_name 获取特定个股资讯，或接入新浪财经/东方财富的 API 获取实时的国内宏观（央行、发改委、证监会）与行业政策。

逻辑修改： 若获取不到个股新闻，强制系统拉取“A股大盘宏观新闻”或“申万一级行业新闻”，严格禁止fallback到全球美股新闻。

P1（高优先级优化）：短线交易模块引入 T+1 与涨跌停约束

缺陷表现： 给出A股无法执行的日内止损或突破追高建议

。

优化方案：

代码级修改： 在 trading\_agent 的后处理逻辑中，加入对目标股票前收盘价的±10%（或20%）计算，若AI给出的买卖点超出此范围，代码直接拦截并打回重做。

Prompt层面： 必须在交易员的System Prompt中强注入A股交易规则（见下文）。

P1（高优先级优化）：全局报告输出语言的中文强制化

缺陷表现： 中英夹杂，影响阅读与A股语境理解

。

优化方案： 全局替换所有Agent的最终输出指令。在所有Agent的 system\_prompt 末尾加入："You must output the final report entirely in Simplified Chinese (zh-CN), including all professional financial terms."

P2（低优先级迭代）：A股特色Alpha因子的引入

优化方案： 在 data\_router 中新增一层 alternative\_data，每天固定拉取 AKShare 的 stock\_lhb\_detail\_em（龙虎榜）和 stock\_hsgt\_north\_net\_flow\_in\_em（北向资金），将这些数据专门喂给情绪分析师（Sentiment Analyst），取代原有的推特/外网情绪分析。

四、 智能体Prompt本土化优化建议

要让DeepSeek真正发挥出A股投研总监的水平，必须在各个角色的System Prompt中“注入A股灵魂”。

1\. 基本面分析师 (Fundamental Analyst)

新增Prompt约束： “你正在分析中国A股市场的标的。除了常规财务指标，你必须重点评估以下因素：1. 政策导向（该行业是否受国家宏观政策鼓励或打压）；2. 国企估值逻辑（中特估，若为国企，需关注其分红率提升与资产注入预期）；3. 业绩预告（A股财报具有季节性炒作特征，需关注财报窗口期的业绩爆雷风险）。在评估流动性比率时，请结合中国特色重资产国企（如水电、煤炭）主要依赖银行信贷滚动展期的实际情况，切勿仅因绝对数值低而机械看空。”

2\. 技术分析师 (Technical Analyst)

新增Prompt约束： “你的分析目标是A股市场，这是一个以\*\*散户交易为主导、受T+1交收规则和涨跌幅限制（10%或20%）\*\*的市场。你的技术分析必须注意：1. 均线突破是否伴随‘涨停板’，若涨停则技术形态有效性增强；2. 缩量跌停或连续一字跌停会导致所有技术指标失真，不可盲目使用RSI超卖抄底；3. 在设置ATR止损位时，必须考虑到T+1导致当天买入无法卖出的风险，止损建议必须以‘次日或波段’为周期。”

3\. 新闻/情绪分析师 (News \& Sentiment Analyst)

新增Prompt约束： “你是一个深谙A股‘政策市’特性的舆情分析师。忽略纳斯达克、美联储等无关外围新闻。你的核心任务是解读：发改委/证监会政策、央行流动性释放（降准降息）、行业补贴政策、以及国内机构资金的板块轮动迹象。如果个股无新闻，请从其所属的申万行业宏观政策进行推演。”

4\. 风险管控与交易员 (Risk \& Execution)

新增Prompt约束： “在制定交易计划时，你必须严格遵守A股规则：1. 无法进行日内T+0回转交易；2. 建仓与平仓价格不得超过昨日收盘价的±10%（主板）或±20%（创业/科创板）；3. 若标的处于‘非交易状态/停牌/ST风险’，必须强制一票否决买入计划并建议空仓；4. 考虑到A股高波动性，短线请适当放大止损容忍度，或采用分批建仓策略防范假突破。”

五、 最终适配性结论与使用建议

最终适配等级：【部分适配 -> 基本适配（处于过渡期）】

综合评估： 在你完成了底层数据路由和国内大模型替换后，TradingAgents已经成功跨越了“能不能跑”的门槛。特别值得赞赏的是你新增的“长线定投（DCA）分析分支”，这一改动堪称点睛之笔，它完美规避了原生框架在A股短线交易中的诸多水土不服，展现出了极高的实操参考价值。然而，原生框架在短线交易规则认知和新闻舆情信息源上的先天缺陷，使得当前的短线模块分析结论存在“逻辑自洽，但脱离A股现实”的问题。

明确使用建议：

对于长线定投分支（DCA）： 已经具备极高的可用性。强烈建议直接用于实盘的小资金参考或ETF定投回测。AI结合定投胜率和宏观周期的分析，能很好地辅助A股“逆向投资”决策。

对于原生短线分支： 当前状态下，绝对禁止用于实盘自动化交易。 建议仅用于研究环境下的模拟盘（Paper Trading）。在完成上文提及的P0和P1级优化（尤其是新闻源替换和T+1规则约束）之前，短线分析报告仅可作为“技术面/财务面的第二意见”供人类研究员参考。

对于问题标的防范： 框架在识别停牌/退市标的（如601298.SH）上表现出色，可以作为机构风控系统的排雷辅助工具。
